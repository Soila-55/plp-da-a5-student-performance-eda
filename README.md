# Student Performance Exploratory Data Analysis (EDA)

## Overview
This project creates a synthetic dataset of 1,200 students and performs exploratory data analysis using Python.

## Objectives
- Inspect dataset structure, data types, and missing values.
- Summarize numerical and categorical variables.
- Detect study-hours outliers using the IQR method.
- Create average scores and performance bands.
- Explore correlations and score differences by gender, school type, and county.
- Compare school-type score gaps across attendance bands and study-hour quartiles.
- Generate charts and a brief findings report.

## Dataset
`student_performance.csv` is generated by the script with random seed 55. It contains student IDs, gender, school type, county, attendance rate, study hours, and subject scores. **The data is synthetic and does not represent real Kenyan students.**

## Requirements
Python 3.9+ recommended. Install dependencies:
```bash
pip install -r requirements.txt
```

## Run
From this repository directory:
```bash
python student_performance_eda.py
```

The script regenerates `student_performance.csv` and the charts in `figures/`.

## Outputs
- `student_performance.csv` — generated dataset
- `figures/distribution_average_score.png` — histogram of average scores
- `figures/average_score_by_county.png` — county mean-score bar chart
- `figures/average_score_boxplot.png` — average-score box plot by performance band

## Important interpretation note
Attendance and study hours are generated independently of subject scores. Therefore, correlations between these variables and average score are expected to be near zero. Correlation does not establish causation.
